# Firishtah Ghyara — portfolio

A responsive, multi-page portfolio with an editorial layout and an earthy palette (warm paper, olive, rust, muted gold). Built with plain HTML, CSS and JavaScript for GitHub Pages.

## Pages
- `index.html` — landing page
- `about.html` — about page (second in the navigation)
- `projects.html` — selected work, including a filterable project list
- `locations.html` — a deliberately restrained page for Mumbai, London and Singapore

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of `firishtah123/Portfolio`.
2. Keep the filenames and the `assets` folder structure intact.
3. Commit the changes. If GitHub Pages is configured for the repository root, the site will update at `https://firishtah123.github.io/Portfolio/`.
4. Add your portrait as `assets/firishtah.jpg` (JPG recommended) to replace the placeholder on the About page.

## Before publishing
- Confirm that every performance figure is accurate and that the relevant benchmark/task can be explained. The 91% figure is explicitly described as task-specific experimental performance, not production accuracy.

- Check that external links still work and that you are comfortable publishing your contact details.

The visual is self-contained; no map tiles or location-tracking widget is used. Google Fonts load online, with system-font fallbacks.
