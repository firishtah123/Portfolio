# Firishtah Ghyara — portfolio

A single-page, continuous-scroll portfolio designed from the supplied visual reference. Built with plain HTML, CSS and JavaScript for GitHub Pages.

## Publish
Upload `index.html`, `styles.css`, and the `assets/` folder to the root of `firishtah123/Portfolio`. Keep the folder structure unchanged. GitHub Pages should publish from `main` and `/ (root)`.

## Replace the photo placeholders
- Portrait: add your photo as `assets/firishtah-portrait.jpg`. In `index.html`, inside `.portrait`, replace the `.upload-note` element with `<img src="assets/firishtah-portrait.jpg" alt="Firishtah Ghyara">`.
- Projects: replace the starter thumbnail files in `assets/` with your own project maps, charts, report screenshots or visualisations. Keep the same filenames to avoid editing HTML, or update the corresponding image paths in `index.html`.
- The current thumbnails are crops from your supplied website-template screenshot, used to echo its imagery and palette. They are visual placeholders, not your original project evidence.
