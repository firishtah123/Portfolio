# Firishtah Ghyara — Portfolio website

Static multi-page portfolio built with HTML, CSS and JavaScript for GitHub Pages.

## Publish on GitHub Pages
1. Upload all files in this folder to the root of `firishtah123/Portfolio`.
2. In GitHub, open Settings → Pages.
3. Choose deploy from the `main` branch and `/ (root)`.
4. Save and wait for Pages to publish.

## Before publishing
- Replace the About portrait placeholder with your chosen photo.
- Add the confirmed CV PDF and link it from `contact.html`.
- Review the provisional skill levels in `skills.html`.
- Verify the education details for Singapore before adding the institution/qualification.
- Add original reports, notebook links and validated findings to each project page.
- Check HDFC confidentiality and employer policies before publishing any work-specific details.
- Add project source URLs to each detail page when confirmed.

## Notes
No external JS libraries are required. Google Fonts are loaded from Google Fonts; fallback fonts are defined in CSS. The StoryMap is a stylised interactive city narrative, not a geospatially accurate route map.
